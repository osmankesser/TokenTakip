Token Tracker 0.1.5 (Windows 64-bit)
====================================

WHAT'S NEW
----------
- Redesigned floating pill navigation with theme-aware colors and smooth transitions
- New Agents page with automatic local agent discovery and detailed agent profiles
- Agent-specific usage advice inside each agent profile
- GitHub Top 100 browser with categories, live data, caching, and in-app project details
- Automatic translation of GitHub descriptions into the selected interface language
- Expanded language support and improved localized interface text
- Improved quota cards, navigation responsiveness, icon sizing, and visual consistency

INSTALLATION
------------
1. Extract TokenTracker-0.1.5-win64.zip.
2. Keep TokenTracker.exe and the _internal folder together.
3. Run TokenTracker.exe.

PRIVACY
-------
- No developer telemetry server
- Quota checks use local sessions and each provider's official API
- Chat analysis remains on your computer
- GitHub translation contacts Google Translate only for public repository descriptions
